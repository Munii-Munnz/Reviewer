Data Structures Fundamentals

Core Concepts

  • Lists: A collection of things arranged in some order.
  • Element: A single item in the List.
  • Index: The numerical position of an Element.

The ArrayList

A list implemented using an array, but it can grow when necessary.

Accessing an Element

Uses its index to retrieve a specific element.

Adding at the End

Adds the new element to the first empty space. Doubles capacity if full.

Adding in the Middle

Elements must shift to the right to make space. Watch the capacity double if needed.

Deleting in the Middle

Elements must shift to the left one by one to close the gap left by the deleted element.

Linked Lists

Parts of a Linked List

  • Head: The first node in the linked list.
  • Tail: The last node in the linked list.
  • Node: An element containing Data and a Pointer (next, and optionally prev).

Use the preset menu at the top to see different list variations!

Linked List: Traversal

Visiting nodes one by one, starting from the Head, following the pointers.

Linked List: Searching

Traverse the list comparing each node's data to find a specific value.

Linked List: Updating

Change a value at a specific node by traversing to it and overwriting the data.

Linked List: Insertion

Add a new node by updating pointers. No shifting of elements is required!

Linked List: Deletion

Remove a node by routing pointers around it. The unlinked node is safely discarded.

Stacks

Introduction and Operations

A LIFO (Last In, First Out) structure. Think of a stack of plates.

  • Push: Add an item to the top.
  • Pop: Remove the item from the top.
  • Peek: View the top item without removing it.

Stack Implementations

Stacks can be built using Arrays (fixed/dynamic size) or Linked Lists (dynamic size). The behavior (LIFO) remains exactly the same.

Overflow & Underflow

Fixed-size stacks have limits. Trying to bypass these limits causes errors.

  • Overflow: Pushing to a Stack that is completely full.
  • Underflow: Popping from a Stack that is completely empty.

Expression Processing

Stacks are used to process Postfix expressions. Push numbers, and when you hit an operator, pop two numbers, apply it, and push the result!
